## Troubleshooting Common Issues

Install issues? Choose a smaller quantisation when the model fails to load due to memory.  
Performance problems? Lower context length if out-of-memory errors appear mid-conversation.  
License/activation? Update GPU drivers when inference falls back to CPU unexpectedly.  
Compatibility? Check disk space before downloading a large model file.  
Update failures? Close other GPU applications to free VRAM for generation.
